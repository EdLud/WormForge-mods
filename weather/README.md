# Weather

Rain, storm clouds and lightning for any profile: select the **Weather** add-on.
Rain falls in layers, splashes on the ground and rings the water and puddles,
each ring stopping at the shore. Lightning lights up the clouds and the sky
behind the land.

With **Lightning** set to `strike`, the lightning acts as the Lightning Strike
does. It aims at mines, oil drums and crates first, else at worms and graves.

The rain sound is from Project X's Rain weather. The lightning is Project X's
Lightning Strike, from `wf-lib/lightning` in the WormForge shared helpers.

`tools/make_weather_art.py` draws the sprites; the tests are in
`tests/weather/`.
