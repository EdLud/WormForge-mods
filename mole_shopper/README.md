# Mole Shopper

popka and 0rang3's Mole Shopper scheme from Project X: the same weapons as
the original, with a nice new FOW.

## The weapons

- **Lantern**: throw a permanent coalition light.
- **Far Sight**: place a stationary coalition light for the rest of the
  round with mouse click.

The Mole Bomb is the stock one with two shots per use. Worms see
110 px round them, a Lantern lights 110 px and Far Sight 155 px; the profile
remembers terrain once seen.
