# Skim Voices

Select the **Skim Voices** add-on and every skim off the water gets a cheer
from the team whose turn it is, in the voice of that team's sound bank:

1. the first skim: **Amazing**
2. the second: **Brilliant**
3. the third: **Excellent**
4. the fourth and every skim after it: **Perfect**

Each worm counts its skims, and every count starts again at the next turn.
A team whose sound bank has no file for a line stays silent for it.

It needs a WormForge with the `wa.on.skim` event.
